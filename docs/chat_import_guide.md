# 聊天记录导入使用指南

## 支持的文件格式

1. **文本文件** (.txt)
   - 每行一条消息
   - 纯文本格式

2. **JSON文件** (.json)
   - 标准JSON格式的聊天记录
   - 支持数组或对象格式

3. **微信数据库文件** (.db)
   - 微信导出的SQLite数据库文件
   - 支持单个文件或整个文件夹导入

4. **其他常见资料**
   - QQ/聊天原生导出文件、ZIP、HTML、CSV、XML
   - PDF、DOCX、常见图片、音频和视频文件
   - 当前里程碑先完成安全上传；各格式的解析、OCR 和语音识别按后续处理器逐步接入

## 导入方式

### 单文件导入
1. 先创建人物并选择父亲、母亲、亲人、朋友、情侣或自定义关系
2. 点击"选择文件"按钮
3. 选择要导入的聊天记录文件
4. 点击"开始导入"按钮

### 文件夹导入
1. 先保存人物身份
2. 点击"选择文件夹"按钮
3. 选择包含聊天记录文件的文件夹
4. 点击"开始导入"按钮

## 微信聊天记录导出方法

### Android设备
1. 使用第三方工具如"微信聊天记录导出助手"
2. 导出为数据库文件(.db)格式
3. 将导出的文件夹上传到本系统

### iOS设备
1. 使用iTunes或爱思助手备份设备
2. 使用第三方工具提取微信聊天记录
3. 导出为数据库文件格式

## 注意事项

1. **文件大小限制**: 单次导入任务默认不超过3 GiB（3,221,225,472 字节）。服务端按任务内所有文件 `total_bytes` 之和判断，不是按单个文件分别判断；客户端按4 MiB分片上传并支持重复分片幂等重试。部署者可通过 `PAST_PARTNER_MAX_IMPORT_BYTES` 调整任务总量上限。
2. **隐私保护**: 原始媒体发送给第三方模型前必须取得按供应商和用途划分的明确授权
3. **数据安全**: 当前本地开发版写入配置的数据目录，并通过回环地址初始化本地 owner Bearer 会话；加密对象存储、OIDC 多用户账户、账户删除和保留期策略属于后续生产阶段，不能视为已经完成
4. **格式要求**: 确保文件格式正确，否则可能导致解析失败

## 支持的数据库文件

- 微信聊天记录数据库 (MicroMsg.db)
- 微信联系人数据库
- 微信媒体文件索引数据库

## 常见问题

### Q: 为什么我的数据库文件无法解析？
A: 可能的原因包括：
- 数据库文件损坏
- 微信版本不兼容
- 文件权限问题
- 加密的数据库文件

### Q: 上传的文件会被保存在哪里？
A: 当前本地开发版保存在启动参数指定的数据目录中，文件名和目录由服务端生成。上传分片、合并对象、人物内容字段以及导入任务/上传清单已使用认证加密 SQLite 或对象存储；随机人物和导入 ID 仍是明文非秘密索引，不能据此承诺静态数据已完整加密。

### Q: 我可以删除已上传的文件吗？
A: 当前里程碑尚未提供用户删除接口或自动保留期清理，生产发布前必须按设计文档补齐账户级删除和可审计的清理策略。
