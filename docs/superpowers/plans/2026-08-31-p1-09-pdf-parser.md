# P1-09 PDF 对话文本解析

## 目标

按原始任务表独立收口 P1-09：将用户主动选择的 PDF 聊天导出解析为统一消息记录，并在可选库不可用或文档部分损坏时保留有界、可审计的纯文本回退。

## 本次范围

- 优先使用可选 `pypdf` 提取页面文本，失败时使用受限的 PDF 文本操作符回退。
- 支持常见 `Tj`/`TJ` 文本操作符、转义字面量和 UTF-8/UTF-16BE/UTF-16LE 十六进制文本。
- 复用统一时间、发送者、正文和消息类型标准化规则，生成稳定 `record_id`。
- 在读取前拒绝非 PDF、加密 PDF、无对话文本、超文件大小和超过 512 页的文档。

## 不在本次范围

- OCR、扫描件图像识别、复杂字体 CMap 还原和版式重建。
- 文档内图片/音频/视频分析、`.doc` 二进制格式和第三方模型调用。

## 验收标准

1. 标准 PDF 和最小文本回退 PDF 可解析为 `generic_pdf` 规范化消息。
2. `Tj`/`TJ` 十六进制 UTF-16 文本不被替换字符破坏，数组成员不会重复采集。
3. 加密、页数超限、非 PDF 和无对话内容均返回稳定的 `ParserError` 编码。
4. 通过 PDF/注册表定向测试、全量测试、编译检查、差异检查和 CodeGraph 同步。
