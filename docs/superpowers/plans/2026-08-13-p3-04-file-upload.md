# P3-04 Flutter 文件选择与分片上传实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Flutter 导入工作区接入多文件选择、SHA-256 分片上传、断点续传和完成刷新。

**Architecture:** 以可按范围读取的文件源隔离平台 API，以 `ImportUploadController` 编排文件清单、缺片查询和串行上传；`ApiClient` 只新增现有服务端端点的类型化方法。页面保留测试替身兼容，同时在应用依赖中注入真实文件选择器。

**Tech Stack:** Flutter/Dart、`file_picker`、`crypto`、`http`、Material 3、Flutter tests。
