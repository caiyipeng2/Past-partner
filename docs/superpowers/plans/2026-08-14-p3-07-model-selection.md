# P3-07 Flutter 模型目录与选择

## 目标

在 Flutter 客户端接入已完成的 P2-01 模型目录与成本估算 API，提供可比较、可重试、可访问的模型选择入口。

## 范围

- 读取 `GET /api/v1/models`，严格校验模型、供应商、能力、上下文和价格元数据。
- 支持按供应商筛选，并在同一列表中比较能力、隐私标签、上下文长度和价格更新时间。
- 使用 `POST /api/v1/models/cost-estimate` 进行输入/输出 token 成本估算；价格缺失时显示明确不可用状态，不在客户端伪造价格。
- 从人物工作区提供“模型”入口；模型页支持选择并返回当前模型，页面内保留选择状态。
- 覆盖加载、空响应、结构错误、服务错误、估算失败、重试和选中状态。

## 非范围

- 不在 Flutter 保存供应商 API Key。
- 不新增服务端模型、供应商或价格配置。
- 不实现聊天请求、模型切换后的对话持久化或后台训练。

## 验收标准

1. API 客户端使用 owner 会话访问模型目录和成本估算，拒绝缺少必填字段、超长列表和非法价格数据。
2. 模型页展示供应商筛选、能力标签、上下文长度、隐私标签、价格更新时间和“未配置价格”状态。
3. 估算请求只发送允许的 provider/model/token 字段，输入输出 token 有界；服务返回 `pricing_unavailable` 时保留页面并提示不可估算。
4. 选择模型有清晰选中态和 44px 以上触控区域，屏幕阅读器可识别模型名称、供应商及选中状态。
5. Flutter focused/all tests、静态检查、Android debug/release 构建和真机启动验收通过后提交。
