# P1-01 通用 CSV 聊天记录解析实现记录

## 目标

按原始 P1 任务表实现通用 CSV 聊天记录解析，并复用现有 `ParserRegistry`、`NormalizedMessage` 和导入预览链路。此任务只覆盖 CSV，不提前实现 XML、SQLite schema 自动探测或媒体解析。

## 行为边界

- 首行必须包含发送者、内容、时间三类字段；支持英文常见别名和中文列名。
- 自动识别逗号、分号、制表符和竖线分隔符，不依赖 `.csv` 扩展名。
- 复用现有 UTF-8、UTF-16 和 GB18030 文本编码检测。
- 使用 `csv.DictReader` 逐行读取，不把整个导入文件加载到内存。
- 缺少必需列返回 `unsupported_format`；损坏行或缺失字段返回 `invalid_record`。
- 继续由注册表统一生成稳定 `record_id`，并支持已有 `max_records` 预览限制。

## 验收证据

- `tests/unit/test_parser_registry.py` 覆盖标准 CSV、UTF-16 分号 CSV、预览截断、缺少必需列和损坏行。
- `npm test`：Python 241 项、Node 4 项全部通过。
- `python -m compileall -q src tests` 和 `git diff --check` 通过。
- CodeGraph 索引已同步，`GenericCsvParser` 已接入内置注册表。

## 后续明确项

CSV 附件列解析、XML 解析和 SQLite schema 自动探测分别属于后续 P1 任务，不在本任务中隐式扩展。
