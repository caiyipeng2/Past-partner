# P1-02 通用 XML 聊天记录解析实现记录

## 目标

按原始 P1 任务表实现通用 XML 聊天记录解析，并复用现有 `ParserRegistry`、`NormalizedMessage` 和导入预览链路。此任务只覆盖 XML，不提前实现通用 HTML 深度解析、DOCX/PDF 或 SQLite schema 自动探测。

## 行为边界

- 支持 `message`、`record`、`item`、`entry`、`chat` 和 `utterance` 等常见消息节点。
- 支持属性或子节点中的发送者、内容、时间和消息类型字段，允许命名空间和常见英文别名。
- 不依赖 `.xml` 扩展名；内容明显是 XML 但没有消息节点时返回 `unsupported_format`。
- 使用 `ElementTree.iterparse` 流式读取，复用 UTF-8、UTF-16 和 GB18030 检测及 `max_records` 限制。
- XML 结构损坏或消息字段缺失返回 `invalid_record`；DOCTYPE/ENTITY 声明返回 `unsupported_format`，包括出现在探测样本之后的声明。

## 验收证据

- `tests/unit/test_parser_registry.py` 覆盖标准 XML、UTF-16 XML、无消息节点、无扩展名内容探测、损坏 XML 和 DTD 安全边界。
- P1-02 定向测试 7 项全部通过。
- 全量回归、编译、差异检查和 CodeGraph 状态将在提交前完成。

## 后续明确项

XML 附件/媒体引用的深度解析和更复杂的厂商专用 schema 分别属于后续任务，不在本任务中隐式扩展。
