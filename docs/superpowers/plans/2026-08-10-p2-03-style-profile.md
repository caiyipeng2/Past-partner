# P2-03 风格画像

## 目标

按 Phase 3 混合学习架构，将解析器输出的 `NormalizedMessage` 转换为与模型供应商无关的风格画像，作为后续记忆、检索和提示词构建的输入边界。

## 本次范围

- 只统计人物身份对应发送者的文本消息，避免把用户消息混入模仿指标。
- 输出消息长度、词汇、标点、表情、回复节奏、情绪倾向、偏好称呼和关系行为统计。
- 接收父母、亲人、朋友、情侣和自定义关系上下文，并对发送者 ID、关系元数据设置长度和枚举边界。
- 通过 `ChatDataParser.generate_style_profile` 接入现有解析器注册表，所有格式先走统一规范化消息链路。
- 输出只包含统计画像和来源类型，不返回原始消息正文。

## 不在本次范围

- 不实现长期记忆、向量索引、提示词编排或微调数据集。
- 不调用任何模型供应商，不上传原始消息或媒体，不生成模拟回复。
- 不实现画像持久化、画像查询 API、后台任务和 Flutter 页面；这些属于后续学习层或客户端任务。

## 验收标准

1. 只有人物发送者的文本消息影响长度、词汇、标点、表情、节奏和情绪统计；用户消息只可作为关系行为计数。
2. 画像包含稳定版本号、计数、使用率、时间间隔和关系上下文；无有效人物文本时返回 `persona_messages_required`。
3. 关系类型不在约定枚举、发送者 ID/称呼/关系标签超出边界或记录不是 `NormalizedMessage` 时明确失败。
4. 画像序列化结果不包含原始正文；偏好称呼和关系元数据经过规范化。
5. 定向单元测试、完整 Python/Node 回归、编译检查和 CodeGraph 同步通过。
