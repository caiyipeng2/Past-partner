# P3-08 Flutter 第三方处理授权实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Flutter 人物工作区提供可审计的第三方媒体处理授权查看、创建和撤回流程，严格复用已完成的 P1-10 精确授权 API。

**Architecture:** 新增独立的 consent domain/gateway/controller/screen 层；`ApiClient` 只封装 `/api/v1/consents` 的 owner 会话请求。人物工作区通过依赖注入打开授权页面，创建表单从已选模型读取供应商和模型，不保存 API Key，不读取或上传媒体正文。

**Tech Stack:** Flutter/Dart、Material 3、现有 `ApiClient`/`Session`、Flutter widget/unit tests。
