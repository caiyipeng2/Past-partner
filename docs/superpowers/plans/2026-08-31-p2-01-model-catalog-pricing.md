# P2-01 模型目录、能力与价格估算

## 目标

按原始设计 Phase 3 的第一项，扩展统一 provider gateway 的模型目录，使 Web、Flutter 和后续训练/媒体任务可以基于同一份能力、上下文、隐私和价格元数据进行选择。价格不写死在客户端，也不伪造实时供应商数据。

## 本任务范围

- 为模型返回能力、上下文长度、区域、隐私元数据和结构化价格信息。
- 支持通过 `PAST_PARTNER_MODEL_PRICING_JSON` 注入供应商或管理员维护的模型价格和刷新时间。
- 静态目录模型和启动时发现的 Ollama/自定义运行时模型使用同一价格配置格式。
- 提供 `POST /api/v1/models/cost-estimate`，按输入 token、输出 token和媒体计费单位返回分项及总估算。
- 价格缺失、模型不存在或用量非法时返回稳定错误，不返回伪造的零成本。
- 保留既有 `input_price`/`output_price` 字段，兼容现有 v1 客户端。

## 不在本任务范围

- 不联网抓取供应商实时价格，不保存 API Key，不承诺价格长期有效。
- 不实现自定义供应商注册、凭据加密仓、模型能力探测、真实媒体调用或训练成本结算。
- 估算不替代供应商最终账单；后续需使用 provider usage 响应记录实际费用。

## 验收标准

1. 模型目录返回结构化 pricing、刷新时间、context_length、regions 和 privacy_metadata。
2. 静态模型和运行时发现模型均能从同一 JSON 配置获得价格。
3. 输入/输出 token 成本按每百万 token 计算，媒体单位可选，分项和总额可复核。
4. 缺价、未知模型、非法用量和坏配置均失败关闭并返回稳定错误。
5. 定向测试、完整回归、编译检查、差异检查和 CodeGraph 均通过，文档与实际行为一致。
