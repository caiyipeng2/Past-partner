# P0-33 QQ 备份包安全解析实现记录

## 目标

对照原始产品大纲，为用户主动选择的 QQ ZIP 备份包提供可复用的、受边界保护的解析入口，输出项目统一的 `NormalizedMessage`。本任务定义并支持项目 manifest v1，不宣称兼容 QQ 私有加密备份格式。

## 范围

- 新增 `qq_backup` parser，要求 ZIP 根目录存在 `manifest.json` 或 `qq-manifest.json`，且 `schema_version=1`、平台标识为 QQ。
- 支持 manifest 内联 `records`，或按清单声明 `generic_json`、`generic_jsonl`、`qq_text`、`qq_html` 消息文件。
- 复用现有解析器注册表，生成稳定 `record_id`，支持预览 `max_records` 截断和有界摘要。
- 解压前后限制条目数量、单条目大小、总展开大小和压缩比，拒绝路径穿越、符号链接、重复条目、嵌套 ZIP、未列出的文件和不支持的内部格式。
- 不读取或猜测私有数据库密钥，不自动聚合目录，不处理媒体和浏览器目录。

## 验收证据

- `tests/unit/test_qq_backup.py` 覆盖成功解析、归档源不变、预览截断、路径穿越、嵌套归档、条目上限、平台校验和损坏 ZIP 稳定错误码。
- 与微信备份测试一起通过后，再执行完整 `npm test`、`compileall`、`git diff --check` 和 CodeGraph 状态核验。
