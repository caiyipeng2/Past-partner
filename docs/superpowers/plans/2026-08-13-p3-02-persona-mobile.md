# P3-02 Flutter 人物列表与创建

## 目标

在已认证的 Flutter 客户端中提供最小可用的人物工作区：读取人物列表、展示空状态、创建人物并在成功后刷新。关系身份支持父亲、母亲、亲人、朋友、情侣和自定义；自定义关系必须填写自定义称呼。

## 实施顺序

1. 先写 Flutter 单元/Widget 红测试，覆盖 API 列表与创建解析、控制器加载/创建状态、空状态入口和创建后列表刷新。
2. 实现 `Persona`、`PersonaGateway`、`PersonaController` 和人物工作区表单，复用现有 `SessionController` 的认证会话与蓝色 Material 3 主题。
3. 将认证后的应用首页切换到人物工作区，并保持连接页、外观预览及现有会话流程不变。
4. 运行人物聚焦测试、全量 `flutter test`、`dart analyze`，再从 ASCII 路径构建 Android Debug/Release APK，检查 Release 清除明文传输。
5. 提交独立功能分支并交付用户验收；用户确认后再合并主分支和推送远端。

## 验收标准

- 已连接服务返回的人物可显示姓名与关系标签。
- 无人物时展示明确的空状态和创建入口，表单具备可访问标签、必填校验和加载/失败反馈。
- 预设关系覆盖父亲、母亲、亲人、朋友、情侣；自定义关系必须填写自定义标签。
- 创建成功后新人物出现在列表中，不需要重启应用或重新配对。
- 网络/服务端失败只显示稳定的用户提示，不把原始响应正文当作 UI 文案。
- Android Debug/Release 可构建；iOS 仅验证共享 Dart 源码，不进行真机打包。
