# P1-07 QQ 原生数据库解析

## 目标

按原始 P1 任务表完成 QQ 原生数据库目录解析或明确返回密钥需求。P0-31 已经提前落地了明文 QQ 消息表解析，本任务在不回退既有实现的前提下补齐常见 SQLite 文件扩展名和 sidecar 快照边界，并校正任务追踪文档。

## 范围

- 支持用户主动选择的 QQ 数据库目录中的 `.db`、`.sqlite`、`.sqlite3` 文件。
- 复制数据库及现有 `-wal`/`-shm` sidecar 后，以只读 URI 和 `query_only` 方式解析。
- 识别常见消息表、发送者、正文、时间和消息类型字段，输出统一 `NormalizedMessage`。
- 对非 SQLite、加密/不可读数据库、未知 schema、目录变化和单文件输入返回稳定错误；不猜测或持久化密钥。

## 不在本任务

- 不自动解密 QQ 私有数据库，不实现密钥提取。
- 不处理 QQ 私有备份包、媒体内容、浏览器目录聚合或 OCR/ASR。

## 验收标准

1. `.db`、`.sqlite`、`.sqlite3` 消息数据库都能解析为统一记录，并生成稳定 `record_id`。
2. 对应的 WAL/SHM sidecar 会进入一致只读快照，源目录不被写入。
3. 单个数据库文件、非 SQLite/不可读数据库和未知 schema 返回稳定错误。
4. 完整回归、编译、差异检查和 CodeGraph 校验通过。
