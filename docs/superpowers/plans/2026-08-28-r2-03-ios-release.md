# R2-03 iOS Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax to track progress.

**Goal:** Make iOS release verification reproducible on macOS while keeping Windows evidence limited to source checks and avoiding false claims about signing or devices.

**Architecture:** A small Python policy checker validates the Flutter version against `ios/Runner/Info.plist` and rejects ATS exceptions without requiring Xcode. A manually-triggered macOS GitHub Actions job runs the checker, Flutter analysis/tests, and an unsigned IPA build; Apple signing/export credentials remain a separate explicitly gated task.

**Tech Stack:** Python 3 standard library, `plistlib`, Flutter/Dart, GitHub Actions, macOS runner.
