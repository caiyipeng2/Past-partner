# P1-08 DOCX 对话文本解析

## 目标

按原始任务表独立收口 P1-08：将用户主动选择的 DOCX 聊天导出解析为统一消息记录，同时保留安全归档边界和可追踪的稳定错误。

## 本次范围

- 只读取受控的 `word/document.xml`，不执行文档脚本、不解析外部关系。
- 将 Word 段落、文本节点、换行（`w:br`/`w:cr`）和制表符（`w:tab`）映射为对话行。
- 复用统一时间、发送者、正文和消息类型标准化规则，生成稳定 `record_id`。
- 在读取前拒绝路径穿越、重复条目、符号链接、嵌套压缩包、DOCTYPE/ENTITY、损坏、超限和无对话内容。

## 不在本次范围

- PDF 解析（原始 P1-09；虽然已有提前落地的兼容实现，但不在本分支重新扩展）。
- `.doc` 二进制格式、OCR、文档内图片/音频/视频内容分析和版式还原。

## 验收标准

1. 标准 DOCX 对话段落可解析为 `generic_docx` 和规范化消息。
2. 同一段落内的 Word 换行和制表符保持为 `\\n` 与 `\\t`，不吞掉消息内容。
3. 无消息、损坏或不安全归档均返回稳定的 `ParserError` 编码，不产生伪成功结果。
4. 通过 DOCX/注册表定向测试、全量测试、编译检查、差异检查和 CodeGraph 同步。
