# P2-05 向量检索

## 目标

按 Phase 3 混合学习架构，从已审核的长期记忆候选中为单次会话选择相关证据，在候选数、token 总量、说话人范围和可选时间窗口内形成可审计结果。

## 范围

- 使用 provider-independent 的确定性稀疏向量（词元重叠）作为当前本地评分器。
- 只检索 `accepted` 候选；`needs_review`、`rejected` 和默认不允许的说话人范围均被排除。
- 返回有限证据文本、稳定 `memory_id`、来源 `record_id`、排序分数和排除计数。
- 原始查询只保存 SHA-256 指纹，不保存向量、不调用 embedding 或聊天供应商。
- 保留结果契约，后续可替换真实 embedding 索引而不改变审核和预算边界。

## 明确不包含

- 长期记忆持久化、向量数据库、embedding API、提示词构建、聊天响应追踪 API。
- 将未审核候选自动发布为事实，或把原始聊天内容发送给第三方。
